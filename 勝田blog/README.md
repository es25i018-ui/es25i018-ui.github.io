# 勝田のVictory Road（ローカルブログサイト）

サーバーもドメインも不要、フォルダごと手元に置くだけで動くブログサイトです。

## 開き方

`index.html` をブラウザ（Chrome, Safari, Edge など）でダブルクリックして開くだけです。
インターネット接続がある場合、見出しに使っているフォント（Google Fonts）が読み込まれます。オフラインでも代替フォントで問題なく表示されます。

## フォルダ構成

```
blog/
├── index.html        記事一覧（トップページ）
├── about.html         プロフィールページ
├── style.css          全ページ共通のデザイン
├── posts/
│   ├── post-1.html    記事「早起きは3億の徳」
│   ├── post-2.html    記事「自己投資という名の消費」
│   ├── post-3.html    記事「人脈という資産クラス」
│   ├── post-4.html    記事「1200万円を溶かした話、それでも後悔していない理由」
│   ├── post-5.html    記事「研究室で学んだ『圧倒的成長』の原点」
│   └── post-6.html    記事「コーチングで外れた『自分ブロック』の正体」
└── README.md          このファイル
```

## 新しい記事の追加方法

1. `posts/` フォルダの中の好きな記事（例: `post-3.html`）をコピーして、`post-4.html` のような新しい名前で保存する。
2. コピーしたファイルの中身を書き換える：
   - `<title>` タグの中の文字
   - `.post-margin` の日付（年と月日）
   - `.post-eyebrow` のカテゴリ名
   - `.post-title` の記事タイトル
   - `.post-body` の中の本文（`<p>` や `<h2>` を自由に追加）
3. `index.html` の `<ul class="entries">` の中に、新しい `<li class="entry">` ブロックをコピー＆編集して追加する（日付・タイトル・リンク先・抜粋文・タグを書き換える）。

## プロフィールの編集

`about.html` の `.about-body` 内の文章を書き換えれば、自己紹介ページになります。

## 公開したくなったら

このフォルダをそのままレンタルサーバーやGitHub Pagesなどにアップロードすれば、そのまま公開サイトとして使えます。
